# Alert Analyzer

Phân tích tình trạng hệ thống và các cảnh báo:
- Tương quan giữa các cảnh báo
- Phân tích xu hướng
- Xác định nguyên nhân gốc rễ
- Trực quan hóa chỉ số
- Phát hiện sự cố chủ động
