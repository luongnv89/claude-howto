## Cách Sử dụng / How to Use

1. **Đánh dấu checkbox** khi file đã được dịch: `- [ ]` → `- [x]`
2. **Cập nhật ngày dịch** trong cột "Ngày Dịch"
3. **Thêm notes** nếu có vấn đề hoặc câu hỏi
4. **Sort theo ưu tiên** từ trên xuống dưới
