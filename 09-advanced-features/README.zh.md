## 规划模式

### 使用方法

**Claude Code:**
```bash
# 启动规划模式
claude --plan

# 或使用斜杠命令
/plan
```

**Kimi Code 适配:**
```bash
# 启动规划模式
kimi --plan

# 或使用斜杠命令
/plan
```

### 工作流程

```
用户请求 ──▶ Claude/Kimi 分析 ──▶ 生成计划 ──▶ 用户确认 ──▶ 执行
                              └─▶ 用户修改 ──▶ 重新生成
```

## 思考标签

### 使用方法

在提示词中使用 `<thinking>` 标签请求逐步推理：

```
请分析这个算法的时间复杂度。
<thinking>
请展示你的推理过程，然后给出最终答案。
</thinking>
```

### 工作原理

```
┌─────────────────────────────────────────────────────────────────┐
│                    思考标签处理                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                │

│            │                                                    │
│            ▼                                                    │
│   ┌─────────────────┐                                           │
│   │  识别思考请求   │                                           │
│   └────────┬────────┘                                           │
│            │                                                    │
│            ▼                                                    │
│   ┌─────────────────────────────────────────────┐               │
│   │              推理阶段                        │               │
│   │                                              │               │
│   │  1. 分析问题                                │               │
```

## 后台任务

### 使用方法

**Claude Code:**
```bash
# 启动后台任务
/background "运行测试套件"

# 查看后台任务
/background-status

# 恢复会话
claude --resume
```

**Kimi Code 适配:**
```bash
# 启动后台任务
/background "运行测试套件"

# 查看后台任务
/background-status

# 恢复会话
kimi --resume
```

### 工作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    后台任务工作流程                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                │
│   1. 启动后台任务                                               │
│            │                                                    │
│            ├─▶ /background "长时间运行的命令"                   │
│            │                                                    │
│            ▼                                                    │
│   2. 任务执行                                                   │
│            │                                                    │
│            ├─▶ 在新进程/线程中运行                              │
│            │                                                    │
│            ├─▶ 主会话继续交互                                   │
│            │                                                    │
│            ▼                                                    │
│   3. 进度监控                                                   │
│            │                                                    │
│            ├─▶ /background-status 查看进度                      │
│            │                                                    │
│            ▼                                                    │
│   4. 完成处理                                                   │
│            │                                                    │
│            ├─▶ 任务完成通知                                     │
│            │                                                    │
│            ├─▶ 结果保存到会话                                   │
│            │                                                    │
│            ▼                                                    │
│   5. 会话恢复（可选）                                           │
│            │                                                    │
│            ├─▶ claude --resume 或 kimi --resume                 │
│            │                                                    │
│            └─▶ 恢复后台任务状态                                 │
│                                                                │
└─────────────────────────────────────────────────────────────────┘
```

## Kimi Code 适配

### 功能对照

| 功能 | Claude Code | Kimi Code |
|------|-------------|-----------|
| 规划模式 | `claude --plan` | `kimi --plan` |
| 思考标签 | `<thinking>` | `<thinking>` |
| 后台任务 | `/background` | `/background` |
| 恢复会话 | `claude --resume` | `kimi --resume` |
| 只读模式 | `claude -r` | `kimi -r` |

### 注意事项

- 高级功能概念在两个工具中相同
- 命令语法和标志一致
- 可以共享相同的工作流程和习惯
- 具体实现可能略有差异

---

## 最佳实践

| 实践 | 原因 | 示例 |
|------|------|------|
| **复杂任务使用规划** | 避免意外修改 | 重构前使用 `--plan` |
| **思考标签用于教学** | 展示推理过程 | "解释为什么..." |
| **长时间任务放后台** | 不阻塞工作流 | 测试、构建 |
| **定期恢复检查** | 防止丢失上下文 | 长时间任务后恢复 |

---

## 故障排除

| 问题 | 检查 | 解决方案 |
|------|------|---------|
| 规划模式不生效 | 标志位置 | 确保在命令开头 |
| 思考标签未显示 | 提示词 | 明确请求推理过程 |
| 后台任务失败 | 权限 | 检查执行权限 |
| 恢复失败 | 状态 | 检查会话状态文件 |
