# 检查点

一个视觉指南，了解如何保存和回滚会话状态以安全实验。

> 📚 **关于本指南**
> 
> 本模块介绍 **Claude Code** 的检查点功能。
> 
> Kimi Code 用户可参考 **Kimi Code 适配**部分了解对应配置。

---

## 快速对照

| Claude Code | Kimi Code |
|-------------|-----------|
| 自动保存 | 自动保存 |
| 手动创建检查点 | 手动创建检查点 |
| 回滚功能 | 回滚功能 |

---

## 概览

检查点让你可以保存会话状态，并在需要时回滚到之前的状态。

```
┌─────────────────────────────────────────────────────────────┐
│                   检查点时间线                               │
├─────────────────────────────────────────────────────────────┤
│                                                            │
│   开始 ──▶ 修改 ──▶ 修改 ──▶ 检查点 ──▶ 修改 ──▶ 回滚      │
│     │                              ▲              │        │
│     └──────────────────────────────┘              ▼        │
│                                      恢复到检查点状态      │
│                                                            │
│   状态 1    状态 2    状态 3    保存     状态 4    状态 3   │
│                                                            │
└─────────────────────────────────────────────────────────────┘
```

### 工作流程

```
工作 ──▶ 创建检查点 ──▶ 实验性修改 ──▶ 不满意 ──▶ 回滚到检查点
                                   ──▶ 满意 ──▶ 继续工作
```

---

## 使用方法

**Claude Code:**
```bash
# 创建检查点（在 Claude Code 中输入）
/create-checkpoint

# 查看检查点列表
/list-checkpoints

# 回滚到检查点
/rollback-to <checkpoint-id>
```

**Kimi Code 适配:**
```bash
# 创建检查点（在 Kimi Code 中输入）
/create-checkpoint

# 查看检查点列表
/list-checkpoints

# 回滚到检查点
/rollback-to <checkpoint-id>
```

## 工作原理

### 检查点系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    检查点系统架构                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                │
│   1. 检查点创建                                                 │
│            │                                                    │
│            ├─▶ 用户: /create-checkpoint                         │
│            │                                                    │
│            ├─▶ 系统捕获：                                       │
│            │      - 当前文件状态                                │
│            │      - 会话上下文                                  │
│            │      - 命令历史                                    │
│            │                                                    │
│            ├─▶ 保存到检查点存储                                 │
│            │                                                    │
│            ▼                                                    │
│   ┌─────────────────────────────────────────────────────┐       │
│   │  检查点存储 (通常位于 .claude/checkpoints/ 或       │       │
│   │  .kimi/checkpoints/)                                 │       │
│   │                                                      │       │
│   │  checkpoint-001/                                     │       │
│   │    ├── files/         # 文件快照                    │       │
│   │    ├── context.json   # 会话上下文                  │       │
│   │    └── metadata.json  # 时间戳、描述                │       │
│   │                                                      │       │
│   └─────────────────────────────────────────────────────┘       │
│                                                                │
│   2. 检查点恢复                                                 │
│            │                                                    │
│            ├─▶ 用户: /rollback-to checkpoint-001                │
│            │                                                    │
│            ├─▶ 系统恢复：                                       │
│            │      - 文件状态                                    │
│            │      - 会话上下文                                  │
│            │                                                    │
│            ├─▶ 确认回滚操作                                     │
│            │                                                    │
│            ▼                                                    │
│   会话恢复到检查点时的状态                                     │
│                                                                │
└─────────────────────────────────────────────────────────────────┘
```

## Kimi Code 适配

### 功能对照

| 功能 | Claude Code | Kimi Code |
|------|-------------|-----------|
| 创建检查点 | `/create-checkpoint` | `/create-checkpoint` |
| 列出检查点 | `/list-checkpoints` | `/list-checkpoints` |
| 回滚 | `/rollback-to` | `/rollback-to` |
| 自动保存 | 支持 | 支持 |
| 存储位置 | `.claude/checkpoints/` | `.kimi/checkpoints/` |

### 注意事项

- 检查点功能在两个工具中概念相同
- 命令语法相同
- 检查点存储位置不同但结构相似
- 可以手动备份检查点目录

---

## 最佳实践

| 实践 | 原因 | 示例 |
|------|------|------|
| **重大修改前创建** | 安全网 | 重构前创建检查点 |
| **命名检查点** | 易于识别 | 使用描述性名称 |
| **定期清理** | 节省空间 | 删除旧检查点 |
| **不依赖长期保存** | 临时功能 | 重要状态使用 git |

---

## 故障排除

| 问题 | 检查 | 解决方案 |
|------|------|---------|
| 检查点未创建 | 权限 | 检查目录写入权限 |
| 回滚失败 | 文件冲突 | 解决冲突后重试 |
| 检查点丢失 | 存储 | 检查 `.claude/` 或 `.kimi/` 目录 |
| 磁盘空间不足 | 清理 | 删除旧检查点 |
