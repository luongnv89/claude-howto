# 子代理

一个视觉指南，了解专业 AI 助手如何并行处理复杂任务。

> 📚 **关于本指南**
> 
> 本模块介绍 **Claude Code** 的子代理功能。
> 
> Kimi Code 用户可参考 **Kimi Code 适配**部分了解对应配置。

---

## 快速对照

| Claude Code | Kimi Code |
|-------------|-----------|
| `~/.claude/agents/` 目录 | `~/.kimi/agents/` 目录 |
| `@agent-name` 调用 | `@agent-name` 调用 |
| `claude agents` 管理 | `kimi agents` 管理 |

---


## 安装

**Claude Code:**
```bash
# 创建代理目录
mkdir -p ~/.claude/agents

# 复制代理定义
cp security-auditor.md ~/.claude/agents/
cp api-designer.md ~/.claude/agents/
cp test-generator.md ~/.claude/agents/

# 在对话中使用：@security-auditor 请审查这段代码
```

**Kimi Code 适配:**
```bash
# 创建代理目录
mkdir -p ~/.kimi/agents

# 复制代理定义
cp security-auditor.md ~/.kimi/agents/
cp api-designer.md ~/.kimi/agents/
cp test-generator.md ~/.kimi/agents/

# 在对话中使用：@security-auditor 请审查这段代码
```

## 代理模板

### 安全审计代理

```markdown
# @security-auditor

## 角色
你是一个安全专家。你的任务是识别代码中的安全漏洞。

## 专业知识
- OWASP Top 10
- 注入攻击（SQL、NoSQL、命令）
- 身份验证和授权缺陷
- 敏感数据暴露
- XXE、SSRF、CSRF
- 不安全的反序列化

## 输出格式
对于每个发现：
- 严重性：🔴 高 / 🟡 中 / 🟢 低
- 类型：漏洞类型
- 位置：文件和行号
- 描述：问题解释
- 修复：代码示例

## 范围
只关注安全问题。不要评论代码风格或性能。
```

### API 设计代理

```markdown
# @api-designer

## 角色
你是一个 API 设计专家。你设计 RESTful、直观、文档完善的 API。

## 原则
1. **资源导向** - URL 是资源，不是动作
2. **一致性** - 所有端点遵循相同模式
3. **版本控制** - API 版本在 URL 中
4. **HTTP 语义** - 正确使用方法、状态码、头

## 输出格式
```
GET /api/v1/{resource}
- 描述
- 参数
- 响应
- 错误
```

## 范围
只关注 API 设计。不实现业务逻辑。
```

## Kimi Code 适配

### 配置路径

| 配置项 | Claude Code | Kimi Code |
|--------|-------------|-----------|
| 代理目录 | `~/.claude/agents/` | `~/.kimi/agents/` |
| 调用语法 | `@agent-name` | `@agent-name` |
| CLI 管理 | `claude agents` | `kimi agents` |
| 代理定义文件 | `.md` 文件 | `.md` 文件 |

### 快速迁移

```bash
# 1. 创建 Kimi Code 代理目录
mkdir -p ~/.kimi/agents

# 2. 复制代理定义
cp ~/.claude/agents/*.md ~/.kimi/agents/

# 3. 在 Kimi Code 中使用相同的调用方式
# @security-auditor 请审查这段代码
```

### 注意事项

- 代理定义格式完全相同
- 调用语法相同（`@agent-name`）
- 可以同时为两个工具维护代理
- 代理可以共享相同的定义文件

## 最佳实践

| 实践 | 原因 | 示例 |
|------|------|------|
| **明确定义角色** | 代理知道专注什么 | "安全专家" 而非 "开发者" |
| **指定输出格式** | 一致、可操作的结果 | 使用结构化模板 |
| **限制范围** | 避免代理冲突 | "只关注安全" |
| **使用描述性名称** | 用户知道调用哪个 | `@security-auditor` |
| **提供示例** | 澄清期望 | 包含输入/输出示例 |

---

## 故障排除

| 问题 | 检查 | 解决方案 |
|------|------|---------|
| 代理未响应 | 目录位置 | 确保在 `~/.claude/agents/` 或 `~/.kimi/agents/` |
| 调用无效 | 名称匹配 | 检查 `@name` 与文件名 |
| 代理行为不一致 | 角色定义 | 明确角色和范围 |
| 结果不合并 | 任务依赖 | 明确指定任务边界 |
