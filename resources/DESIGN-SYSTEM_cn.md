# Claude How To - 设计系统

## 视觉标识

### 图标设计概念：带有代码括号的指南针

Claude How To 图标使用**带有 `>` 代码括号的指南针**来表示通过代码进行引导导航：

```
     N (绿色)
     ▲
     │
W ───>─── E     指南针 = 引导/方向
     │          > 括号 = 代码/终端/CLI
     ▼
     S (黑色)
```

这带来了：
- **视觉清晰度**：直观地传达"代码导航指南"的含义
- **象征意义**：指南针 = 找到方向；`>` = 代码/终端
- **可扩展性**：在 16px 到 512px 的任意尺寸下都能正常显示
- **品牌一致性**：以极简调色板契合开发者工具的审美

## 色彩系统

### 调色板

| 颜色 | Hex | RGB | 用途 |
|-------|-----|-----|-------|
| 黑色（主色） | `#000000` | 0, 0, 0 | 主笔画、文字、南针 |
| 白色（背景） | `#FFFFFF` | 255, 255, 255 | 浅色背景 |
| 灰色（辅助色） | `#6B7280` | 107, 114, 128 | 次要刻度线、辅助文字 |
| 亮绿色（强调色） | `#22C55E` | 34, 197, 94 | 北针、中心点、强调线条 |
| 近黑色（深色背景） | `#0A0A0A` | 10, 10, 10 | 深色模式背景 |

### 对比度比率（WCAG）

- 黑色在白色上：**21:1** AAA
- 灰色在白色上：**4.6:1** AA
- 绿色在白色上：**3.2:1**（仅用于装饰，不用于文字）
- 白色在深色上：**19.5:1** AAA

### 强调色使用规则

**亮绿色（#22C55E）仅用于高亮：**
- 指南针北针
- 中心点
- 强调下划线/边框
- 永远不作为背景色使用
- 永远不用于正文文字

## 图标细节

### 指南针规格

指南针标志由以下几何元素构成：

```
元素               | 描边/填充      | 颜色
--------------------|----------------|------------------
外圈               | 3px 描边       | 黑色 / 白色（深色模式）
北向刻度            | 2.5px 描边     | 黑色 / 白色（深色模式）
其他基本刻度        | 2px 描边       | 灰色 / 白色 50%（深色模式）
间隔刻度            | 1.5px 描边     | 灰色 / 白色 40%（深色模式）
北针               | 填充多边形     | #22C55E（始终为绿色）
南针               | 填充多边形     | 黑色 / 白色（深色模式）
> 括号             | 3px 描边       | 黑色 / 白色（深色模式）
中心点             | 填充圆形       | #22C55E（始终为绿色）
```

### 尺寸递进

```
16px  → 仅圆环 + 指针 + 尖括号（最简版）
32px  → 添加基本刻度线
64px  → 添加间隔刻度线
128px → 完整细节，所有元素清晰锐利
256px → 最大细节，较粗描边
```

## 自定义

### 更改强调色

要创建使用不同强调色的变体：

1. 将所有 `#22C55E` 替换为你的强调色
2. 确保装饰元素的对比度仍高于 3:1
3. 保持黑/白/灰的基础结构不变

### 缩放

```css
svg {
  width: 256px;
  height: 256px;
}
```

SVG 通过 viewBox 自动缩放——无需变换。
