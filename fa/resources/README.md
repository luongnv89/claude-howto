# Claude How To — دارایی‌های برند

مجموعه کامل لوگوها، آیکون‌ها و faviconهای پروژه Claude How To. تمام دارایی‌ها از طراحی V3.0 استفاده می‌کنند: یک قطب‌نما با نماد براکت کد (`>`) که نشان‌دهنده ناوبری راهنما در کد است — با پالت سیاه/سفید/خاکستری و رنگ تأکیدی سبز روشن (#22C55E).

## ساختار پوشه‌ها

```
resources/
├── logos/
│   ├── claude-howto-logo.svg       # لوگوی اصلی - حالت روشن (520×120px)
│   └── claude-howto-logo-dark.svg  # لوگوی اصلی - حالت تاریک (520×120px)
├── icons/

    ├── favicon-32.svg              # favicon - ۳۲×۳۲px (اصلی)
```

## مرور دارایی‌ها

### مفهوم طراحی (V3.0)

**قطب‌نما با براکت کد** — راهنمایی به‌همراه کد:
- **حلقه قطب‌نما** = ناوبری، یافتن مسیر
- **سوزن شمال (سبز)** = جهت، پیشرفت در مسیر یادگیری
- **سوزن جنوب (مشکی)** = استوار بودن، پایه محکم
- **براکت `>`** = پرامپت ترمینال، کد، بافت CLI
- **علامت‌های درجه‌بندی** = دقت، یادگیری ساختاریافته

### لوگوها

**فایل‌ها**:
- `logos/claude-howto-logo.svg` (حالت روشن)
- `logos/claude-howto-logo-dark.svg` (حالت تاریک)

**مشخصات**:
- **اندازه**: 520×120 پیکسل
- **هدف**: لوگوی سربرگ/برندینگ اصلی با کلمه‌نشان
- **کاربرد**:
  - سربرگ‌های وب‌سایت
  - بَج‌های README
  - مواد بازاریابی
  - مواد چاپی
- **قالب**: SVG (کاملاً مقیاس‌پذیر)
- **حالت‌ها**: روشن (پس‌زمینه سفید) و تاریک (پس‌زمینه #0A0A0A)

### آیکون‌ها

**فایل‌ها**:
- `icons/claude-howto-icon.svg` (حالت روشن)
- `icons/claude-howto-icon-dark.svg` (حالت تاریک)

**مشخصات**:
- **اندازه**: 256×256 پیکسل
- **هدف**: آیکون برنامه، آواتارها، تصاویر بندانگشتی
- **کاربرد**:
  - آیکون‌های برنامه
  - آواتارهای پروفایل
  - تصاویر بندانگشتی شبکه‌های اجتماعی
  - سربرگ‌های مستندات
- **قالب**: SVG (کاملاً مقیاس‌پذیر)
- **حالت‌ها**: روشن (پس‌زمینه سفید) و تاریک (پس‌زمینه #0A0A0A)

**عناصر طراحی**:
- حلقه قطب‌نما با علامت‌های درجه‌بندی اصلی و میان‌جهتی
- سوزن شمال سبز (جهت/راهنمایی)
- سوزن جنوب مشکی (پایه)
- براکت کد `>` در مرکز (ترمینال/CLI)
- نقطه مرکزی سبز به‌عنوان رنگ تأکیدی

### Faviconها

نسخه‌های بهینه‌شده در اندازه‌های متعدد برای استفاده وب:

| فایل | اندازه | DPI | کاربرد |
|------|------|-----|-------|
| `favicon-16.svg` | ۱۶×۱۶ پیکسل | 1x | زبانه‌های مرورگر (مرورگرهای قدیمی) |
| `favicon-32.svg` | ۳۲×۳۲ پیکسل | 1x | favicon استاندارد مرورگر |
| `favicon-64.svg` | ۶۴×۶۴ پیکسل | 1x-2x | نمایشگرهای High-DPI |
| `favicon-128.svg` | ۱۲۸×۱۲۸ پیکسل | 2x | آیکون لمسی اپل، بوک‌مارک‌ها |
| `favicon-256.svg` | ۲۵۶×۲۵۶ پیکسل | 4x | مرورگرهای مدرن، آیکون‌های PWA |

**یادداشت‌های بهینه‌سازی**:
- 16px: هندسه حداقلی — فقط حلقه، سوزن‌ها و چورون
- 32px: علامت‌های درجه‌بندی اصلی را اضافه می‌کند
- 64px+: جزئیات کامل با علامت‌های میان‌جهتی
- همگی یکپارچگی بصری یکسانی با آیکون اصلی دارند
- قالب SVG نمایش واضح در هر اندازه‌ای را تضمین می‌کند

## پالت رنگ

### رنگ‌های اصلی
- **مشکی**: `#000000` (متن اصلی، خطوط، سوزن جنوب)
- **سفید**: `#FFFFFF` (پس‌زمینه‌های روشن)
- **خاکستری**: `#6B7280` (متن ثانویه، علامت‌های درجه‌بندی کوچک)

### رنگ تأکیدی
- **سبز روشن**: `#22C55E` (سوزن شمال، نقطه مرکزی، خطوط تأکیدی — فقط برای برجسته‌سازی، هرگز به‌عنوان پس‌زمینه)

### حالت تاریک
- **پس‌زمینه**: `#0A0A0A` (تقریباً مشکی)

### راهنمای استفاده
- از مشکی برای متن اصلی و عناصر ساختاری استفاده کنید
- از خاکستری برای عناصر ثانویه/پشتیبان استفاده کنید
- از سبز **فقط** برای برجسته‌سازی استفاده کنید — سوزن، نقاط، خطوط تأکیدی
- هرگز از سبز به‌عنوان رنگ پس‌زمینه استفاده نکنید
- کنتراست WCAG AA را حفظ کنید (حداقل 4.5:1)

## راهنمای طراحی

### استفاده از لوگو
- روی پس‌زمینه‌های سفید یا تاریک (#0A0A0A) استفاده کنید
- به‌صورت متناسب مقیاس کنید
- فضای خالی اطراف لوگو را رعایت کنید (حداقل: ارتفاع لوگو / ۲)
- از variantهای روشن/تاریک ارائه‌شده برای پس‌زمینه‌های مناسب استفاده کنید

### استفاده از آیکون
- در اندازه‌های استاندارد استفاده کنید: 16، 32، 64، 128، 256px
- نسبت‌های قطب‌نما را حفظ کنید
- به‌صورت متناسب مقیاس کنید

### استفاده از Favicon
- از اندازه مناسب بافت استفاده کنید
- 16-32px: زبانه‌های مرورگر، بوک‌مارک‌ها
- 64px: آیکون‌های سایت favicon
- 128px+: صفحه‌خانه اپل/اندروید

## بهینه‌سازی SVG

تمام فایل‌های SVG طراحی flat بدون گرادیان یا فیلتر هستند:
- هندسه تمیز مبتنی بر stroke
- بدون raster جاسازی‌شده
- مسیرهای بهینه‌شده
- viewBox واکنش‌گرا

برای بهینه‌سازی وب:
```bash
# فشرده‌سازی SVG با حفظ کیفیت
svgo --config='{
  "js2svg": {
    "indent": 2
  },
  "plugins": [
    "convertStyleToAttrs",
    "removeRasterImages"
  ]
}' input.svg -o output.svg
```

## تبدیل PNG

برای تبدیل SVG به PNG جهت پشتیبانی مرورگرهای قدیمی:

```bash
# با استفاده از ImageMagick
convert -density 300 -background none favicon-256.svg favicon-256.png

# با استفاده از Inkscape
inkscape -D -z --file=favicon-256.svg --export-png=favicon-256.png
```
