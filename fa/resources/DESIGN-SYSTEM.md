# Claude How To — سیستم طراحی

## هویت بصری

### مفهوم طراحی آیکون: قطب‌نما با براکت کد

آیکون Claude How To از **قطب‌نما با براکت کد `>`** استفاده می‌کند تا ناوبری راهنما در کد را نشان دهد:

```
     N (green)
     ▲
     │
W ───>─── E     Compass = Guidance/Direction
     │          > Bracket = Code/Terminal/CLI
     ▼
     S (black)
```

این طراحی ایجاد می‌کند:
- **وضوح بصری**: فوراً «راهنمای ناوبری کد» را منتقل می‌کند
- **معنای نمادین**: قطب‌نما = یافتن مسیر؛ `>` = کد/ترمینال
- **مقیاس‌پذیری**: در هر اندازه‌ای از ۱۶px تا 512px کار می‌کند
- **هماهنگی برند**: با پالت حداقلی با زیب‌شناسی ابزار توسعه‌دهنده مطابقت دارد

## سیستم رنگ

### پالت

| رنگ | Hex | RGB | کاربرد |
|-------|-----|-----|-------|
| مشکی (اصلی) | `#000000` | 0, 0, 0 | خطوط اصلی، متن، سوزن جنوب |
| سفید (پس‌زمینه) | `#FFFFFF` | 255, 255, 255 | پس‌زمینه‌های روشن |
| خاکستری (ثانویه) | `#6B7280` | 107, 114, 128 | علامت‌های درجه‌بندی کوچک، متن ثانویه |
| سبز روشن (تأکیدی) | `#22C55E` | 34, 197, 94 | سوزن شمال، نقطه مرکزی، خطوط تأکیدی |
| تقریباً مشکی (پس‌زمینه تاریک) | `#0A0A0A` | 10, 10, 10 | پس‌زمینه‌های حالت تاریک |

### نسبت‌های کنتراست (WCAG)

- مشکی روی سفید: **21:1** AAA
- خاکستری روی سفید: **4.6:1** AA
- سبز روی سفید: **3.2:1** (فقط تزئینی، نه برای متن)
- سفید روی تاریک: **19.5:1** AAA

### قانون رنگ تأکیدی

**سبز روشن (#22C55E) فقط برای برجسته‌سازی رزرو شده است:**
- سوزن شمال قطب‌نما
- نقطه مرکزی
- خطوط/حاشیه‌های تأکیدی
- هرگز به‌عنوان رنگ پس‌زمینه
- هرگز برای متن بدنه

### جزئیات آیکون

### مشخصات قطب‌نما

نشان قطب‌نما از این عناصر هندسی ساخته شده است:

```
Element             | Stroke/Fill    | Color
--------------------|----------------|------------------
Outer ring          | 3px stroke     | Black / White (dark mode)
North tick          | 2.5px stroke   | Black / White (dark mode)
Other cardinal ticks| 2px stroke     | Gray / White 50% (dark mode)
Intercardinal ticks | 1.5px stroke   | Gray / White 40% (dark mode)
North needle        | filled polygon | #22C55E (always green)
South needle        | filled polygon | Black / White (dark mode)
> bracket           | 3px stroke     | Black / White (dark mode)
Center dot          | filled circle  | #22C55E (always green)
```

### پیشرفت اندازه

```
16px  → Ring + needles + chevron only (minimal)
32px  → Adds cardinal tick marks
64px  → Adds intercardinal tick marks
128px → Full detail, all elements crisp
256px → Maximum detail, thick strokes
```

## دسترس‌پذیری

### کنتراست رنگ
- تمایک متن WCAG AA را برآورده می‌کند (حداقل 4.5:1)
- سبز تأکیدی تزئینی است، نه اطلاعاتی
- هیچ وابستگی رنگی قرمز-سبز وجود ندارد

- اشکال هندسی در 16px قابل تشخیص می‌مانند

## سفارشی‌سازی

### تغییر رنگ تأکیدی

برای ایجاد variant با رنگ تأکیدی متفاوت:

1. تمام نمونه‌های `#22C55E` را با رنگ تأکیدی خود جایگزین کنید
2. اطمینان حاصل کنید نسبت کنتراست بالای 3:1 برای عناصر تزئینی باقی بماند
3. ساختار مشکی/سفید/خاکستری را بدون تغییر نگه دارید

### مقیاس‌گذاری

```css
svg {
  width: 256px;
  height: 256px;
}
```

فایل‌های SVG به‌صورت خودکار از طریق viewBox مقیاس می‌شوند — نیازی به transform نیست.
