# استانداردهای ماژول API

این فایل برای همه‌چیز در /src/api/ مکمل CLAUDE.md ریشه است. فایل‌های حافظه
به‌صورت الحاقی خوانده می‌شوند، نه جایگزین — CLAUDE.md ریشه همچنان معتبر است و Claude Code
این فایل را هنگام خواندن، نوشتن یا ویرایش فایل‌ها در این زیرشاخه به‌صورت درخواستی بارگذاری می‌کند.

## استانداردهای مخصوص API

### اعتبارسنجی درخواست
- برای اعتبارسنجی طرح‌واره از Zod استفاده کنید
- همیشه ورودی را اعتبارسنجی کنید
- در صورت خطای اعتبارسنجی، 400 برگردانید
- جزئیات خطا در سطح فیلد را نیز ارائه دهید

### احراز هویت
- همه نقاط پایانی به توکن JWT نیاز دارند
- توکن در هدر Authorization قرار می‌گیرد
- توکن پس از ۲۴ ساعت منقضی می‌شود
- سازوکار توکن نوسازی (refresh token) را پیاده‌سازی کنید

### قالب پاسخ

همه پاسخ‌ها باید از این ساختار پیروی کنند:

```json
{
  "success": true,
  "data": { /* actual data */ },
  "timestamp": "2025-11-06T10:30:00Z",
  "version": "1.0"
}
```

پاسخ‌های خطا:
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "User message",
    "details": { /* field errors */ }
  },
  "timestamp": "2025-11-06T10:30:00Z"
}
```

### صفحه‌بندی
- از صفحه‌بندی مبتنی بر نشانگر (cursor) استفاده کنید، نه offset
- مقدار بولی `hasMore` را شامل شوید
- حداکثر اندازه صفحه را ۱۰۰ قرار دهید
- اندازه پیش‌فرض صفحه: ۲۰

### محدودسازی نرخ درخواست
- ۱۰۰۰ درخواست در ساعت برای کاربران احراز هویت‌شده
- ۱۰۰ درخواست در ساعت برای نقاط پایانی عمومی
- در صورت عبور از حد، 429 برگردانید
- هدر retry-after را شامل شوید

### کش‌کردن
- برای کش کردن نشست از Redis استفاده کنید
- مدت کش: ۵ دقیقه به‌صورت پیش‌فرض
- در عملیات نوشتن، کش را باطل کنید
- کلیدهای کش را با نوع منبع برچسب‌گذاری کنید
