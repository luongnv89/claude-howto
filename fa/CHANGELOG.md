## [v2.1.245] — 2026-08-25

### همگام‌سازی مستندات با Claude Code v2.1.245

Claude Code از v2.1.235 (2026-08-19) به **v2.1.245** (2026-08-25) رفت — ده
انتشار. این مدخل همان همگام‌سازی را ثبت می‌کند.

> **توجه**: این تغییرنگار برای همگام‌سازی‌های v2.1.233 و v2.1.235 هیچ مدخلی
> ندارد (کامیت‌های `deb7e5c` و `da6e09e`)؛ این‌ها بدون مدخل تغییرنگار
> وارد مخزن شدند. این شکاف به‌جای پر شدن با تاریخ‌های بازسازی‌شده،
> همین‌جا ثبت می‌شود.

### رفع‌شده

- **ادعاهای به‌روزبودن نسخه کهنه و متناقض بودند** — فایل ریشه
  `README.md` در یک جا `v2.1.235` و در جای دیگر `v2.1.220 (July 2026)` را
  می‌گفت، و بالاترین مدخل این تغییرنگار هنوز v2.1.220 را نسخه فعلی
  Claude Code می‌نامید. اکنون همه v2.1.245 را می‌گویند.
- **مهلت پیش‌فرض هوک** از ۶۰ ثانیه به **۶۰۰** برای
  `command`، `http` و `mcp_tool` اصلاح شد (۳۰ برای `prompt`، ۶۰ برای `agent`)، و
  بازنویسی‌های هر رویداد نیز مستند شد.
- **اولویت مهارت** به **enterprise > personal > project** اصلاح شد؛
  درس، project و personal را جابه‌جا کرده بود و با آزمون خودش تناقض داشت.
- **فایل‌های حافظه به هم الحاق می‌شوند، نه بازنویسی** — دو رشته آخر
  «overrides root CLAUDE.md» در `02-memory/README.md` جایگزین شد.
- **`SECURITY.md`** دیگر پشتیبانی از «1.x releases» را تبلیغ نمی‌کند.
- **`STYLE_GUIDE.md`** دیگر پانوشت کهنه را با مثال آموزش نمی‌دهد.
- مطالب نمره‌دار (مهارت‌های `lesson-quiz` و `self-assessment`) با درس‌هایی که
  نمره می‌دهند هم‌تراز شد: ۳۱ رویداد هوک، پنج نوع هوک، شش گزینه
  rewind، شش حالت مجوز، عمق import برابر ۴.

### افزوده‌شده

- **ترنسپورت MCP با WebSocket (`ws`)** — یک ترنسپورت چهارم، که از طریق
  `.mcp.json` یا `claude mcp add-json` پیکربندی می‌شود.
- **سبک خروجی `Concise`** — پنجمین سبک داخلی (v2.1.237).
- **کلیدهای تنظیمات جدید** — `modelPicker`، `promptCacheTtl`،
  `subagentPromptCacheTtl`، `modelPricing`، `keybindingFlavor`.
- متغیر محیطی **`ANTHROPIC_DEFAULT_MODEL`** (v2.1.236).
- **`/design`** — پیش‌نمایش پژوهشی بوم طراحی.
- **`notify_when_idle`** در `SendMessage` بین‌نشستی (v2.1.236).
- **فیلدهای مانیفست پلاگین** — `workflows`، `channels`، `dependencies` و
  افزوده‌های مرتبط CLI.

### تغییر‌یافته

- **Remote Control** از پیش‌نمایش پژوهشی خارج شد؛ دستگاه‌هایی که
  `claude remote-control` را اجرا می‌کنند اکنون به‌صورت کارت دستگاه در اپ Claude دیده می‌شوند.

- **`commands/` پلاگین** قدیمی علامت‌گذاری شد؛ `skills/` راهنمای فعلی است.
