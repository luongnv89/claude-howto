## مرحله ۱ — زیرساخت و ماژول‌های ضعیف (آوریل ۲۰۲۶)

**نقطه عطف هدف: M1**

### ستون ۴: آغازگر تازه‌وارد

- [ ] **T-001** — نوشتن `scripts/quickstart.sh`
  - پوشه `~/.claude/` را تشخیص می‌دهد (در صورت نبود، با تأیید کاربر می‌سازد)
  - اولین slash command + CLAUDE.md + skill را در راه‌انداز کاربر کپی می‌کند
  - خط agent-discovery را به CLAUDE.md اضافه می‌کند که به AGENT-INDEX.md پیوند دارد
  - Idempotent: فایل‌های موجود را با هشدار رد می‌کند، هرگز جای‌گذاری نمی‌کند
  - گام‌های بعدی را پس از تکمیل چاپ می‌کند

- [ ] **T-002** — ایجاد `QUICKSTART.md` (راهنمای تصویری ۱۵ دقیقه اول)
  - مراحل ترمینال توضیح‌دار به‌عنوان بلوک‌های کد (در صورت امکان از اسکرین‌شات PNG پرهیز کنید؛ ASCII یا Mermaid را ترجیح دهید)
  - مستند کنید کدام دستورات هر تصویر را تولید می‌کنند تا بتوانند دوباره ضبط شوند

- [ ] **T-003** — افزودن بَج دشواری به تمام READMEهای ۱۰ ماژول
  - قالب: `> 🟢 **Beginner** | ⏱ 30 minutes` در بالای هر README ماژول
  - پیش‌نمایش بولت «چه چیزی می‌سازید» را در زیر بَج اضافه کنید

### ستون ۷: برنامه‌درس زنده

- [ ] **T-004** — ایجاد `WHATS-NEW.md`
  - قالب: `## CC vX.X — DATE` با آیتم‌های بولت به ازای هر تغییر ویژگی
  - حداقل یک ورودی برای نسخه فعلی CC اضافه کنید

- [ ] **T-005** — افزودن بَج نسخه به تمام READMEهای ۱۰ ماژول
  - قالب: `> ✅ Verified against Claude Code **vX.X.X** · Last verified: YYYY-MM-DD`
  - `cc_version_verified` را به frontmatter هر ماژول اضافه کنید

- [ ] **T-006** — ایجاد `.github/workflows/staleness-check.yml`
  - برنامه: دوشنبه‌ها به‌صورت هفتگی 09:00 UTC
  - تاریخ `last_verified` هر ماژول را از frontmatter می‌خواند (از `yq` یا اسکریپت ۱۰ خطی Python استفاده کنید)
  - برای هر ماژولی که ۳۰+ روز تأیید نشده، یک GitHub Issue ایجاد می‌کند
  - اگر Issue باز با همان عنوان از قبل وجود داشته باشد رد می‌شود

### ستون ۶: کیفیت محتوا (CLAUDE.md)

- [ ] **T-007** — ایجاد `CLAUDE.md` ریشه برای پروژه
  - بهترین روش‌ها را به‌عنوان پیکربندی خود پروژه نشان می‌دهد
  - قراردادهای مشارکت، ساختار ماژول و گردش کار نگهداری را مستند می‌کند

### ستون ۲: ایندکس ایجنت هوش مصنوعی (ژنراتور)

- [ ] **T-008** — نوشتن `scripts/build-agent-index.py`
  - تمام ۱۰ فایل README ماژول را می‌خواند
  - استخراج می‌کند: سرفصل‌ها (→ topics)، بلوک‌های کد (→ examples با تگ زبان)، جدول‌ها (→ reference data)
  - `agent-manifest.json` با schema تعریف‌شده در طرح CEO خروجی می‌دهد
  - `AGENT-INDEX.md` (خلاصه قابل خواندن توسط انسان) خروجی می‌دهد
  - تأیید می‌کند که ارجاعات به فایل‌های واقعی اشاره می‌کنند
