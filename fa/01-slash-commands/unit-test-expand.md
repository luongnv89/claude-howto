# گسترش تست‌های واحد

تست‌های واحد موجود را متناسب با فریم‌ورک تست پروژه گسترش دهید:

1. **تحلیل پوشش**: اجرای گزارش پوشش برای شناسایی شاخه‌های تست‌نشده، موارد لبه و نواحی کم‌پوشش
2. **شناسایی شکاف‌ها**: بازبینی کد برای شاخه‌های منطقی، مسیرهای خطا، شرایط مرزی، ورودی‌های null/خالی
3. **نوشتن تست‌ها** با فریم‌ورک پروژه:
   - Jest/Vitest/Mocha (JavaScript/TypeScript)
   - pytest/unittest (Python)
   - Go testing/testify (Go)
   - فریم‌ورک تست Rust (Rust)
4. **هدف‌گیری سناریوهای خاص**:
   - مدیریت خطا و استثناءها
   - مقادیر مرزی (min/max، خالی، null)
   - موارد لبه و موارد گوشه
   - انتقال حالت و عوارض جانبی
5. **تأیید بهبود**: اجرای پوشش مجدد، تأیید افزایش قابل سنجش

تنها بلوک‌های کد تست جدید را ارائه دهید. از الگوهای تست موجود و قراردادهای نام‌گذاری پیروی کنید.
