## حالت‌های مجوز

Claude Code از ۶ حالت مجوز پشتیبانی می‌کند که نحوه تأیید استفاده از ابزار را کنترل می‌کنند.

| حالت | توضیح | زمان استفاده |
|------|-------------|-------------|
| `manual` | پرسش برای هر فراخوانی ابزار | بازبینی شخصی هر اقدام (از نسخه 2.1.200 به‌صورت Manual نمایش داده می‌شود؛ مقدار پیکربندی هنوز `default` است و `manual` یک مستعار است). از نسخه 2.1.283، حالت auto حالت شروع داخلی برای نشست‌های ترمینال تعاملی و VS Code است؛ اجراهای `claude -p` و Agent SDK از نسخه 2.1.302 در Manual شروع می‌شوند، پس فراخوانی‌هایی که به تأیید نیاز دارند رد می‌شوند مگر چیزی آن‌ها را تأیید کند |
| `acceptEdits` | پذیرش خودکار ویرایش فایل‌ها، پرسش برای بقیه | جریان‌های کاری ویرایش قابل اعتماد |
| `plan` | پژوهش و پیشنهاد یک طرح؛ بدون ویرایش منبع تا زمان تأیید شما | برنامه‌ریزی و کاوش |
| `auto` | همه اقدامات، با بررسی‌های طبقه‌بند ایمنی پس‌زمینه | وظایف طولانی، کاهش خستگی ناشی از پرامپت |
| `bypassPermissions` | نادیده گرفتن همه بررسی‌های مجوز | CI/CD، محیط‌های بدون رابط |
| `dontAsk` | رد کردن ابزارهایی که نیازمند مجوز هستند | اسکریپت‌نویسی غیرتعاملی |

> **توجه**: حالت `auto` نیازمند طرح، مدل و ارائه‌دهنده واجد شرایط است — به [09-advanced-features/](09-advanced-features/#auto-mode) مراجعه کنید. از `bypassPermissions` فقط در محیط‌های قابل اعتماد و سندباکس‌شده استفاده کنید.

**مرجع**: [مستندات رسمی](https://code.claude.com/docs/en/permissions)

## زیرایجنت‌ها

دستیارهای هوش مصنوعی تخصصی با زمینه‌های ایزوله برای وظایف مشخص.

> **ایجاد تودرتوی زیرایجنت‌ها به‌طور پیش‌فرض فعال است، عمق ۳ (نسخه 2.1.219)**: زیرایجنت‌ها می‌توانند زیرایجنت‌های خودشان را تا سه لایه زیر گفتگوی اصلی ایجاد کنند. برای تغییر این محدودیت `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` را تنظیم کنید، یا آن را `1` بگذارید تا تودرتویی غیرفعال شود. (تاریخچه: نسخه‌های 2.1.172 تا 2.1.216 به‌طور پیش‌فرض تا ۵ لایه تودرتو می‌شدند بدون امکان تغییر؛ نسخه 2.1.217 تودرتویی را اختیاری و در عمق ۱ کرد؛ نسخه 2.1.219 پیش‌فرض را ۳ قرار داد.) برای نحو `Agent(agent_type)` که تعیین می‌کند یک زیرایجنت مجاز است کدام زیرایجنت‌ها را ایجاد کند، به [04-subagents/README.md](04-subagents/README.md#محدودکردن-زیرایجنت‌های-قابل‌ساخت) مراجعه کنید.

### زیرایجنت‌های داخلی

## نصب کامل با یک دستور

نصب همه مثال‌های این مخزن:

```bash
# ایجاد دایرکتوری‌ها
mkdir -p .claude/{commands,agents,skills} ~/.claude/{hooks,skills}

# نصب همه ویژگی‌ها
cp 01-slash-commands/*.md .claude/commands/ && \
cp 02-memory/project-CLAUDE.md ./CLAUDE.md && \
cp -r 03-skills/* ~/.claude/skills/ && \
cp 04-subagents/*.md .claude/agents/ && \
cp 06-hooks/*.sh ~/.claude/hooks/ && \
chmod +x ~/.claude/hooks/*.sh
```
