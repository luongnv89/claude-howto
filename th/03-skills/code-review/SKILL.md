# Code Review Skill

skill นี้ให้ความสามารถในการตรวจสอบโค้ดอย่างครอบคลุม โดยมุ่งเน้นที่:

1. **การวิเคราะห์ความปลอดภัย (Security Analysis)**
   - ปัญหา authentication/authorization
   - ความเสี่ยงจากการเปิดเผยข้อมูล
   - ช่องโหว่ injection
   - ความอ่อนแอของ cryptography
   - การบันทึกข้อมูลที่ละเอียดอ่อน

2. **การตรวจสอบประสิทธิภาพ (Performance Review)**
   - ประสิทธิภาพ algorithm (การวิเคราะห์ Big O)
   - การเพิ่มประสิทธิภาพ memory
   - การเพิ่มประสิทธิภาพ database query
   - โอกาสในการใช้ caching
   - ปัญหา concurrency

3. **คุณภาพโค้ด (Code Quality)**
   - หลัก SOLID
   - design pattern
   - รูปแบบการตั้งชื่อ
   - เอกสาร
   - ความครอบคลุมของ test

4. **ความสามารถในการบำรุงรักษา (Maintainability)**
   - ความสามารถอ่านโค้ด
   - ขนาด function (ควรน้อยกว่า 50 บรรทัด)
   - ความซับซ้อน cyclomatic
   - การจัดการ dependency
   - ความปลอดภัยของ type

## ไฟล์อ้างอิง

skill นี้มีไฟล์สนับสนุนที่ควรอ่านเมื่อทำการตรวจสอบ:

- **`templates/review-checklist.md`** — checklist แบบมีโครงสร้างครอบคลุมความปลอดภัย, ประสิทธิภาพ, คุณภาพ, และการทดสอบ อ่านไฟล์นี้และใช้เป็นแนวทางเพื่อให้ไม่พลาดหมวดหมู่ใดในระหว่างการตรวจสอบ
- **`templates/finding-template.md`** — template มาตรฐานสำหรับจัดทำเอกสารการค้นพบแต่ละรายการพร้อม severity, ตำแหน่ง, ตัวอย่างโค้ด, และการวิเคราะห์ผลกระทบ อ่านไฟล์นี้และใช้รูปแบบเมื่อรายงานปัญหา
- **`scripts/analyze-metrics.py`** — Python script ที่คำนวณ code metric (จำนวน function, จำนวน class, ความยาวบรรทัดเฉลี่ย, คะแนนความซับซ้อน) รันบนไฟล์ที่ตรวจสอบเพื่อรวบรวมข้อมูลเชิงปริมาณ
- **`scripts/compare-complexity.py`** — Python script ที่เปรียบเทียบความซับซ้อน cyclomatic และ cognitive ระหว่างไฟล์สองเวอร์ชัน รันด้วยเวอร์ชัน before และ after เมื่อตรวจสอบการ refactoring

## template การตรวจสอบ

สำหรับโค้ดแต่ละส่วนที่ตรวจสอบ ให้นำเสนอ:

### สรุป
- การประเมินคุณภาพโดยรวม (1-5)
- จำนวนการค้นพบสำคัญ
- พื้นที่ที่ควรให้ความสำคัญก่อน

### ปัญหาวิกฤต (ถ้ามี)
- **ปัญหา**: คำอธิบายชัดเจน
- **ตำแหน่ง**: ไฟล์และหมายเลขบรรทัด
- **ผลกระทบ**: เหตุผลว่าทำไมต้องแก้ไข
- **Severity**: Critical/High/Medium
- **การแก้ไข**: ตัวอย่างโค้ด

### การค้นพบตามหมวดหมู่

#### ความปลอดภัย (ถ้าพบปัญหา)
รายการช่องโหว่ความปลอดภัยพร้อมตัวอย่าง

#### ประสิทธิภาพ (ถ้าพบปัญหา)
รายการปัญหาประสิทธิภาพพร้อมการวิเคราะห์ความซับซ้อน

#### คุณภาพ (ถ้าพบปัญหา)
รายการปัญหาคุณภาพโค้ดพร้อมคำแนะนำ refactoring

#### ความสามารถในการบำรุงรักษา (ถ้าพบปัญหา)
รายการปัญหาด้านการบำรุงรักษาพร้อมการปรับปรุง
