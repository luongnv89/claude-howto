# Brand Voice Skill

## ภาพรวม
skill นี้ช่วยให้การสื่อสารทั้งหมดคงความสอดคล้องของ brand voice, โทนเสียง, และข้อความ

## อัตลักษณ์ของแบรนด์

### พันธกิจ
ช่วยให้ทีมพัฒนา automation ใน workflow ด้วย AI

### คุณค่า
- **ความเรียบง่าย**: ทำให้สิ่งซับซ้อนกลายเป็นเรื่องง่าย
- **ความน่าเชื่อถือ**: การทำงานที่มั่นคงแข็งแกร่ง
- **การเสริมพลัง**: เปิดโอกาสให้ความคิดสร้างสรรค์ของมนุษย์

### โทนเสียง (Tone of Voice)
- **เป็นมิตรแต่เป็นมืออาชีพ** - เข้าถึงได้โดยไม่ลดความเป็นทางการ
- **ชัดเจนและกระชับ** - หลีกเลี่ยงศัพท์เฉพาะ อธิบายแนวคิดทางเทคนิคอย่างเข้าใจง่าย
- **มั่นใจ** - รู้ว่าตัวเองกำลังทำอะไร
- **เข้าอกเข้าใจ** - เข้าใจความต้องการและปัญหาของผู้ใช้

## แนวทางการเขียน

### สิ่งที่ควรทำ ✅
- ใช้ "คุณ" เมื่อกล่าวถึงผู้อ่าน
- ใช้ประโยค active voice: "Claude สร้างรายงาน" ไม่ใช่ "รายงานถูกสร้างโดย Claude"
- เริ่มด้วย value proposition
- ใช้ตัวอย่างที่เป็นรูปธรรม
- ประโยคไม่เกิน 20 คำ
- ใช้รายการเพื่อความชัดเจน
- รวม call-to-action

### สิ่งที่ไม่ควรทำ ❌
- ห้ามใช้ศัพท์องค์กรที่คลุมเครือ
- ห้ามพูดอุปมาอุปมัยหรือทำให้ง่ายเกินไป
- ห้ามใช้ "เราเชื่อว่า" หรือ "เราคิดว่า"
- ห้ามใช้ตัวพิมพ์ใหญ่ทั้งหมดนอกจากเน้นความสำคัญ
- ห้ามสร้างกำแพงข้อความ
- ห้ามสันนิษฐานว่าผู้อ่านมีความรู้ทางเทคนิค

## คำศัพท์

### ✅ คำที่แนะนำ
- Claude (ไม่ใช่ "the Claude AI")
- Code generation (ไม่ใช่ "auto-coding")
- Agent (ไม่ใช่ "bot")
- Streamline (ไม่ใช่ "revolutionize")
- Integrate (ไม่ใช่ "synergize")

### ❌ คำที่ควรหลีกเลี่ยง
- "Cutting-edge" (ใช้กันมากเกินไป)
- "Game-changer" (คลุมเครือ)
- "Leverage" (ศัพท์องค์กร)
- "Utilize" (ใช้ "use" แทน)
- "Paradigm shift" (ไม่ชัดเจน)

## ตัวอย่าง

### ✅ ตัวอย่างที่ดี
"Claude automates your code review process. Instead of manually checking each PR, Claude reviews security, performance, and quality—saving your team hours every week."

เหตุผลที่ดี: มี value ชัดเจน, ระบุประโยชน์เฉพาะเจาะจง, เน้นการกระทำ

### ❌ ตัวอย่างที่ไม่ดี
"Claude leverages cutting-edge AI to provide comprehensive software development solutions."

เหตุผลที่ไม่ดี: คลุมเครือ, ใช้ศัพท์องค์กร, ไม่มี value ที่เฉพาะเจาะจง
