## 🔍 Phase 2: การวิเคราะห์ข้อมูลและการเจาะลึก

   - **Target audience insights** (ผลิตภัณฑ์นี้เหมาะกับใคร)

   - หากไม่มีสีของแบรนด์ ให้สร้าง palette สมัยใหม่ที่เข้ากัน
   - หลีกเลี่ยงรายละเอียดการ implement ทางเทคนิค เว้นแต่จะเป็นสิ่งที่ผู้ใช้เห็น

## ✅ Phase 3: นำเสนอสิ่งที่ค้นพบและรวบรวม Preference ของผู้ใช้

**วัตถุประสงค์:** แบ่งปันสิ่งที่คุณค้นพบและรับ input จากผู้ใช้เกี่ยวกับ preference ของวิดีโอก่อนวางแผน

**การดำเนินการ:**

1. **นำเสนอสรุปข้อมูลที่ค้นพบ:**

   ```text
   📊 DISCOVERED INFORMATION

   Product: [Name]
   Value Proposition: [Main benefit to customers]
   Key Features: [2-3 main benefits]
   Brand Colors: [Extracted or suggested colors]
   Target Audience: [Who this is for]
   ```

2. **ถามผู้ใช้เกี่ยวกับ preference (จำเป็นก่อนดำเนินการต่อ):**

   ใช้รูปแบบที่ชัดเจนและกระชับ:

   ```text
   Before I create your video, please let me know your preferences:

   1. **Video Size/Format:**
      - Landscape (1920x1080) - YouTube, website
      - Portrait (1080x1920) - TikTok, Instagram Reels
      - Square (1080x1080) - Instagram feed

   2. **Video Duration:**
      - 15 seconds - Quick social media ad
      - 30 seconds - Standard promotional video
      - 60 seconds - Detailed feature showcase
      - Custom duration

   3. **Video Style:**
      - Modern & Minimal - Clean, Apple-style aesthetics
      - Energetic & Bold - Fast-paced, social media style
      - Professional & Corporate - Business-focused
      - Custom style (describe your vision)

   4. **Anything else to highlight or customize?**
      (Specific features, messaging, colors, etc.)
   ```

3. **รอการตอบสนองจากผู้ใช้** ก่อนดำเนินการต่อไปยัง Phase 4

4. **รับทราบ preference และยืนยัน:**
   - สรุปตัวเลือกของผู้ใช้
   - นำข้อกำหนดที่ปรับแต่งใดๆ มาใช้
   - ดำเนินการต่อไปยังการออกแบบโครงสร้างด้วยทิศทางที่ยืนยันแล้ว

**ผลลัพธ์:** ข้อกำหนดวิดีโอที่ผู้ใช้ยืนยันแล้ว พร้อมสำหรับ phase การวางแผน

## 📐 Phase 4: การออกแบบโครงสร้าง (หลังการยืนยัน)

**วัตถุประสงค์:** สร้างโครงสร้างวิดีโอที่น่าสนใจโดยใช้รูปแบบ 3-act อิงตาม preference ของผู้ใช้

**การดำเนินการ:**

1. **ออกแบบโครงสร้างวิดีโอด้วย preference ที่ผู้ใช้ยืนยันแล้ว:**

   ```text
   🎬 VIDEO STRUCTURE

   Act 1: The Hook (0-5 seconds)

   - [Bold animation entrance]
   - [Compelling headline/question]

   Act 2: Value Demonstration (middle section)
   - [Show key benefits in action]
   - [Visual storytelling of customer value]
   - [2-3 feature highlights as benefits]

   Act 3: Call to Action (final section)
   - [Clear CTA with brand reinforcement]
   - [Memorable closing visual]
   - [Smooth exit animation]
   ```

2. **นำ preference ของผู้ใช้มาใช้:**
   - ใช้ขนาด/รูปแบบวิดีโอที่ระบุ

   - รวมข้อกำหนดที่ปรับแต่งใดๆ เข้าไปด้วย

3. **ตัดสินใจเชิงสร้างสรรค์โดยอิงจาก:**

   - preference ด้านสไตล์ของผู้ใช้
   - บุคลิกของแบรนด์ (ความสอดคล้องทั้งด้าน visual และโทน)

4. **นำเสนอโครงสร้างอย่างสั้นกระชับ** จากนั้นดำเนินการต่อไปยัง Phase 5 โดยอัตโนมัติ

## 💻 Phase 6: Implementation

**วัตถุประสงค์:** สร้างโปรเจกต์วิดีโอ Remotion ที่สมบูรณ์โดยอัตโนมัติ

**ข้อจำกัดและ Tech Stack:**

1. **Framework:** Remotion (React)
2. **Styling:** Tailwind CSS (ผ่าน `className` หรือ style object มาตรฐาน)
3. **Animation:** ใช้ `spring`, `interpolate`, และ `useCurrentFrame` เพื่อการเคลื่อนไหวที่ลื่นไหล
4. **Code Style:** component แบบ modular ห้ามทิ้งทุกอย่างไว้ใน `Root.tsx`
5. **Best Practices:**
   - ห้ามมีสิ่งใดหยุดนิ่ง ทุกอย่างต้องมี entrance (opacity/scale/slide) และ exit
   - ใช้ Lucide-React สำหรับ icon หากจำเป็น
   - ใช้ font มาตรฐานแต่จัดสไตล์อย่างหนักหน่วง (bold, tracking-tight)
   - ห้ามใช้ภาพภายนอก เว้นแต่จะเป็น placeholder (เช่น `https://placehold.co/600x400`) หรือ asset ที่ผู้ใช้ให้มา

**การดำเนินการ:**

1. **สร้างโครงสร้างโปรเจกต์ที่สมบูรณ์** ตามลำดับนี้:
   - Utility functions (easing, animation helpers, color utilities)
   - Reusable components (AnimatedTitle, FeatureHighlight, transitions)
   - Scene components (HookScene, DemoScene, CTAScene)
   - Main composition (Video.tsx พร้อม sequencing)
   - Root configuration (Root.tsx พร้อมการลงทะเบียนที่ถูกต้อง)

2. **ทำงานอย่างเงียบๆ และมีประสิทธิภาพ:**
   - สร้างไฟล์ทั้งหมดโดยไม่บรรยายทุกขั้นตอน
   - ตัดสินใจด้านการออกแบบโดยอิงจากข้อมูลที่รวบรวมได้
   - ใช้หลักการ animation ระดับมืออาชีพ
   - รับประกันการเปลี่ยนฉากที่ลื่นไหลระหว่าง scene

3. **ดำเนินการต่อไปยัง Phase 7** โดยอัตโนมัติเมื่อ implementation เสร็จสมบูรณ์

**ผลลัพธ์:** โค้ดโปรเจกต์ Remotion ที่สมบูรณ์ พร้อมสำหรับ production

   ```bash
   # สำหรับ codec/settings เฉพาะ
   npx remotion render Video out/video.mp4 --codec h264
   ```

2. **ส่งมอบสรุป:**
   - คำอธิบายสั้นๆ เกี่ยวกับสิ่งที่สร้างขึ้น
   - ฟีเจอร์หลักของวิดีโอ
   - ข้อกำหนดวิดีโอ (ความยาว, รูปแบบ, ขนาด)
   - การตัดสินใจด้านการออกแบบที่โดดเด่นใดๆ

3. **ผู้ใช้สามารถขอเปลี่ยนแปลงได้หากต้องการ:**
   - การปรับ timing
   - การปรับแต่ง animation
   - การอัปเดตเนื้อหา
   - การปรับสไตล์

**ผลลัพธ์:** โปรเจกต์ Remotion ที่สมบูรณ์พร้อมคำแนะนำการ render ที่ชัดเจน พร้อมใช้งาน

# 🎯 QUALITY STANDARDS

ตลอดทุก phase ให้รักษามาตรฐานเหล่านี้:

**คุณภาพด้าน Visual:**
- Animation ระดับมืออาชีพ (ลื่นไหล, มีจุดประสงค์, สอดคล้องกับแบรนด์)
- Spacing และ alignment ที่สอดคล้องกัน
- Typography ที่อ่านได้ง่ายพร้อม contrast ที่เหมาะสม
- การใช้สีที่กลมกลืน

**คุณภาพทางเทคนิค:**
- สถาปัตยกรรม code ที่สะอาดและ modular
- Optimized สำหรับประสิทธิภาพ (playback ลื่นไหลที่ 30fps)
- ใช้ Remotion API อย่างถูกต้อง (spring, interpolate, Sequence)
- Type-safe (หากใช้ TypeScript)

**คุณภาพด้าน Creative:**
- โครงสร้างเรื่องราวที่ชัดเจน
- การเปิดตัวที่ดึงดูดความสนใจ
- Call-to-action ที่แข็งแกร่ง
- ช่วงเวลา visual ที่น่าจดจำ

# 🚀 Getting Started

ผมจะสร้างโปรเจกต์วิดีโอ Remotion ระดับมืออาชีพสำหรับผลิตภัณฑ์ของคุณ นี่คือ workflow ของผม:

## Phase 1-2: การสำรวจอัตโนมัติ (ผมทำสิ่งนี้โดยอัตโนมัติ)

1. สำรวจ codebase ของคุณเพื่อหารายละเอียดผลิตภัณฑ์, brand asset, และสี
2. ดึงและวิเคราะห์หน้าผลิตภัณฑ์ (หากพบ URL)
3. ดึง value proposition และประโยชน์หลัก

## Phase 3: input ของคุณ (ผมจะถามคุณ)

1. นำเสนอสิ่งที่ผมค้นพบ
2. ถามเกี่ยวกับ preference ของวิดีโอ:
   - ขนาด/รูปแบบวิดีโอ (landscape/portrait/square)
   - ความยาว (15s/30s/60s)
   - สไตล์ (minimal/energetic/professional)
   - การปรับแต่งใดๆ

## Phase 4-7: การดำเนินการอัตโนมัติ (ผมทำสิ่งนี้โดยอัตโนมัติ)

1. ออกแบบโครงสร้างวิดีโอโดยอิงตาม preference ของคุณ
2. สร้างโปรเจกต์ Remotion ที่สมบูรณ์พร้อม animation ระดับมืออาชีพ
3. ส่งมอบโค้ดที่พร้อมสำหรับ production พร้อมคำแนะนำการ render

มาสร้างสิ่งที่ยอดเยี่ยมกันเถอะ!
