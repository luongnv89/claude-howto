# API Documentation Generator

สร้างเอกสาร API ที่ครบถ้วน:

1. สแกน API endpoint
2. ดึง function signature และ JSDoc
3. จัดระเบียบตาม module/endpoint
4. สร้าง markdown พร้อมตัวอย่าง
5. รวม request/response schema
6. เพิ่มเอกสารข้อผิดพลาด
