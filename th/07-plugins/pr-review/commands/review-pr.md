# PR Review

คำสั่งนี้เริ่มกระบวนการตรวจสอบ pull request อย่างสมบูรณ์ ซึ่งประกอบด้วย:

1. การวิเคราะห์ความปลอดภัย
2. การตรวจสอบ coverage ของ test
3. การอัปเดตเอกสาร
4. การตรวจสอบคุณภาพโค้ด
5. การประเมินผลกระทบด้านประสิทธิภาพ
