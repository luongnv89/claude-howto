# Test Coverage Check

วิเคราะห์ coverage และคุณภาพของ test:

1. ตรวจสอบเปอร์เซ็นต์ coverage ของ test
2. ระบุ code path ที่ยังไม่มีการทดสอบ
3. ตรวจสอบคุณภาพของ test
4. แนะนำ test case ที่ยังขาดอยู่
5. ตรวจสอบว่า edge case ครอบคลุมแล้วหรือไม่
