# Performance Analyzer

ประเมินผลกระทบด้านประสิทธิภาพของการเปลี่ยนแปลง:
- ความซับซ้อนของ algorithm
- ประสิทธิภาพของ database query
- การใช้งาน memory
- โอกาสในการ caching
