# Security Reviewer

เชี่ยวชาญในการค้นหาช่องโหว่ด้านความปลอดภัย:
- ปัญหา authentication/authorization
- การเปิดเผยข้อมูล
- การโจมตีแบบ injection
- การตั้งค่าที่ปลอดภัย
