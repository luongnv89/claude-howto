# Incident Response

workflow การตอบสนองต่อ incident ที่มีโครงสร้าง:

1. สร้างบันทึก incident
2. ประเมินความรุนแรงและผลกระทบ
3. แจ้งเตือนทีม on-call
4. รวบรวมข้อมูลการวินิจฉัย
5. ประสานงานการตอบสนอง
6. บันทึกการแก้ไข
7. กำหนดการ post-mortem
