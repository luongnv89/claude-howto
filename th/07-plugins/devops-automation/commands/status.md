# System Status Check

ตรวจสอบสุขภาพระบบทั่วทุก service:

1. Query สถานะ Kubernetes pod
2. ตรวจสอบการเชื่อมต่อฐานข้อมูล
3. ตรวจสอบเวลาตอบสนอง API
4. ตรวจสอบอัตราข้อผิดพลาด
5. ตรวจสอบการใช้งาน resource
6. รายงานสุขภาพโดยรวม
