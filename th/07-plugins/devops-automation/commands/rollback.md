# Rollback Deployment

Rollback เป็นเวอร์ชันเสถียรก่อนหน้า:

1. ระบุ deployment ก่อนหน้า
2. ตรวจสอบว่า rollback target ทำงานปกติ
3. ดำเนินการขั้นตอน rollback
4. รันการตรวจสอบสุขภาพ
5. แจ้งเตือนทีม
