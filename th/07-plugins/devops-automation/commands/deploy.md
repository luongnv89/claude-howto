# Deploy แอปพลิเคชัน

ดำเนินการ deployment workflow:

1. รันการตรวจสอบก่อน deployment
2. Build แอปพลิเคชัน
3. รันการทดสอบ
4. Deploy ไปยังสภาพแวดล้อมเป้าหมาย
5. รันการตรวจสอบสุขภาพ
6. แจ้งเตือนทีมบน Slack
