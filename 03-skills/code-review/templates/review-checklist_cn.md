# 代码审查清单

## 安全清单
- [ ] 无硬编码凭证或密钥
- [ ] 对所有用户输入进行输入验证
- [ ] SQL 注入防护（参数化查询）
- [ ] 状态更改操作的 CSRF 保护
- [ ] 通过适当转义防止 XSS
- [ ] 受保护端点的认证检查
- [ ] 资源的授权检查
- [ ] 安全密码哈希（bcrypt、argon2）
- [ ] 日志中无敏感数据
- [ ] 强制使用 HTTPS

## 性能清单
- [ ] 无 N+1 查询
- [ ] 适当使用索引
- [ ] 在有益处的地方实施缓存
- [ ] 主线程上无阻塞操作
- [ ] 正确使用 async/await
- [ ] 大型数据集已分页
- [ ] 数据库连接已池化
- [ ] 正则表达式已优化
- [ ] 无不必要的对象创建
- [ ] 防止内存泄漏

## 质量清单
- [ ] 函数 < 50 行
- [ ] 变量命名清晰
- [ ] 无重复代码
- [ ] 适当的错误处理
- [ ] 注释解释"为什么"而非"是什么"
- [ ] 生产代码中无 console.log
- [ ] 类型检查（TypeScript/JSDoc）
- [ ] 遵循 SOLID 原则
- [ ] 设计模式应用正确
- [ ] 代码自文档化

## 测试清单
- [ ] 已编写单元测试
- [ ] 边缘情况已覆盖
- [ ] 错误场景已测试
- [ ] 存在集成测试
- [ ] 覆盖率 > 80%
- [ ] 无不稳定测试
- [ ] 已模拟外部依赖
- [ ] 测试名称清晰
