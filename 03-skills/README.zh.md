# 技能

一个视觉指南，了解可复用的自动化功能如何与你的工作流程集成。

> 📚 **关于本指南**
> 
> 本模块介绍 **Claude Code** 的技能系统。
> 
> Kimi Code 用户可参考 **Kimi Code 适配**部分了解对应配置。

---

## 快速对照

| Claude Code | Kimi Code |
|-------------|-----------|
| `~/.claude/skills/` 目录 | `~/.kimi/skills/` 目录 |
| `CLAUDE.md` 激活 | `KIMI.md` 激活 |
| `@skill-name` 引用 | `@skill-name` 引用 |

---

## 概览

技能是可复用的自动化功能，可以注入到你的项目中，为你提供现成的能力。

## 安装

**Claude Code:**
```bash
# 创建技能目录
mkdir -p ~/.claude/skills

# 复制技能
cp -r code-review ~/.claude/skills/

# 在你的 CLAUDE.md 中激活
echo "@code-review" >> CLAUDE.md
```

**Kimi Code 适配:**
```bash
# 创建技能目录
mkdir -p ~/.kimi/skills

# 复制技能
cp -r code-review ~/.kimi/skills/

# 在你的 KIMI.md 中激活
echo "@code-review" >> KIMI.md
```

## 技能模板

### 代码审查技能

```markdown
# @code-review

## 能力
执行全面的代码审查，关注：
- 代码质量和可维护性
- 安全漏洞
- 性能问题
- 测试覆盖率

## 审查清单

### 代码质量
- [ ] 函数是否小而专注？
- [ ] 变量名是否清晰？
- [ ] 是否有重复代码？
- [ ] 错误处理是否完善？

### 安全
- [ ] 输入是否已验证？
- [ ] 是否有 SQL 注入风险？
- [ ] 敏感数据是否已处理？

### 性能
- [ ] 是否有 N+1 查询？
- [ ] 算法复杂度是否合理？
- [ ] 是否有内存泄漏风险？

## 使用方法
运行 `/review` 或引用代码并询问 "请审查此代码"
```

## Kimi Code 适配

### 配置路径

| 配置项 | Claude Code | Kimi Code |
|--------|-------------|-----------|
| 技能目录 | `~/.claude/skills/` | `~/.kimi/skills/` |
| 激活文件 | `CLAUDE.md` | `KIMI.md` |
| 引用语法 | `@skill-name` | `@skill-name` |
| 技能定义文件 | `CLAUDE.md` | `KIMI.md` |

### 快速迁移

```bash
# 1. 创建 Kimi Code 技能目录
mkdir -p ~/.kimi/skills

# 2. 复制技能
cp -r ~/.claude/skills/* ~/.kimi/skills/

# 3. 重命名技能定义文件（可选）
find ~/.kimi/skills -name "CLAUDE.md" -exec sh -c 'mv "$1" "${1%/*}/KIMI.md"' _ {} \;

# 4. 在项目中使用 KIMI.md 激活
echo "@code-review" >> KIMI.md
```

### 注意事项

- 技能语法和格式完全相同
- 引用方式相同（`@skill-name`）
- 可以同时保留 Claude Code 和 Kimi Code 的技能
- 技能定义文件可以命名为 CLAUDE.md 或 KIMI.md，根据你的主要工具选择

## 最佳实践

| 实践 | 原因 | 示例 |
|------|------|------|
| **专注单一责任** | 易于理解和维护 | "代码审查" 而非 "开发助手" |
| **清晰的使用说明** | 用户知道如何激活 | 包含调用命令 |
| **可配置** | 适应不同项目 | 使用环境变量或参数 |
| **版本控制** | 跟踪变更 | 技能目录使用 git |
| **文档化能力** | 用户知道技能能做什么 | 清单格式 |

## 故障排除

| 问题 | 检查 | 解决方案 |
|------|------|---------|
| 技能未激活 | 目录位置 | 确保在 `~/.claude/skills/` 或 `~/.kimi/skills/` |
| 引用无效 | 技能名称 | 检查目录名与 `@name` 匹配 |
| 上下文未加载 | 定义文件 | 确保有 CLAUDE.md / KIMI.md |
| 与其他技能冲突 | 命名空间 | 使用描述性名称 |
