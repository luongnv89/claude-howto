# Claude How To - 디자인 시스템

## 시각적 아이덴티티

### 아이콘 디자인 콘셉트: 코드 브래킷이 있는 나침반

Claude How To 아이콘은 **`>` 코드 브래킷이 있는 나침반**으로 코드 사이를 안내받으며 길을 찾는 모습을 표현합니다.

```
     N (green)
     ▲
     │
W ───>─── E     나침반 = 안내/방향
     │          > 브래킷 = 코드/터미널/CLI
     ▼
     S (black)
```

이 디자인의 효과는 다음과 같습니다.
- **시각적 명확성**: "코드 내비게이션 가이드"라는 의미를 즉시 전달합니다.
- **상징적 의미**: 나침반 = 길 찾기, `>` = 코드/터미널
- **확장성**: 16px부터 512px까지 어떤 크기에서도 동작합니다.
- **브랜드 일관성**: 최소한의 팔레트로 개발자 도구 특유의 미학과 어울립니다.

## 색상 시스템

### 팔레트

| Color | Hex | RGB | Usage |
|-------|-----|-----|-------|
| 검정 (기본) | `#000000` | 0, 0, 0 | 주요 선, 텍스트, 남쪽 바늘 |
| 흰색 (배경) | `#FFFFFF` | 255, 255, 255 | 밝은 배경 |
| 회색 (보조) | `#6B7280` | 107, 114, 128 | 작은 눈금, 보조 텍스트 |
| 밝은 초록 (강조) | `#22C55E` | 34, 197, 94 | 북쪽 바늘, 중앙 점, 강조선 |
| 검정에 가까운 색 (다크 배경) | `#0A0A0A` | 10, 10, 10 | 다크 모드 배경 |

### 대비율 (WCAG)

- 흰색 위 검정: **21:1** AAA
- 흰색 위 회색: **4.6:1** AA
- 흰색 위 초록: **3.2:1** (장식용으로만 사용, 텍스트에는 사용하지 않음)
- 다크 배경 위 흰색: **19.5:1** AAA

### 강조 색상 규칙

**밝은 초록(#22C55E)은 하이라이트에만 사용합니다.**
- 나침반 북쪽 바늘
- 중앙 점
- 강조 밑줄/테두리
- 배경색으로는 절대 사용하지 않음
- 본문 텍스트에는 절대 사용하지 않음

## 아이콘 세부 사항

### 나침반 사양

나침반 마크는 다음 기하학적 요소로 구성됩니다.

```
Element             | Stroke/Fill    | Color
--------------------|----------------|------------------
Outer ring          | 3px stroke     | Black / White (dark mode)
North tick          | 2.5px stroke   | Black / White (dark mode)
Other cardinal ticks| 2px stroke     | Gray / White 50% (dark mode)
Intercardinal ticks | 1.5px stroke   | Gray / White 40% (dark mode)
North needle        | filled polygon | #22C55E (always green)
South needle        | filled polygon | Black / White (dark mode)
> bracket           | 3px stroke     | Black / White (dark mode)
Center dot          | filled circle  | #22C55E (always green)
```

### 크기별 단계

```
16px  → Ring + needles + chevron only (minimal)
32px  → Adds cardinal tick marks
64px  → Adds intercardinal tick marks
128px → Full detail, all elements crisp
256px → Maximum detail, thick strokes
```

## 크기 지침

### 로고 크기

- **최소**: 너비 200px(웹 기준)
- **권장**: 520px(원본 크기)
- **최대**: 제한 없음(벡터 형식)
- **가로세로 비율**: 약 4.3:1(너비:높이)

### 아이콘 크기

- **최소**: 16px(파비콘)
- **권장**: 64-256px(앱, 아바타)
- **최대**: 제한 없음(벡터 형식)
- **가로세로 비율**: 1:1(정사각형)

## 여백 및 정렬

### 로고 여백

```
┌─────────────────────────────────────┐
│                                     │
│        Clear Space Minimum          │
│         (logo height / 2)           │
│                                     │
│    [COMPASS]  Claude                │
│               How-To                │
│                                     │
└─────────────────────────────────────┘
```

### 아이콘 중심점

모든 아이콘은 캔버스의 중앙을 중심으로 합니다.
- 256px 캔버스는 128×128
- 128px 캔버스는 64×64
- 다른 UI 요소와의 정렬을 유지합니다.

## 접근성

### 색상 대비
- 모든 텍스트가 WCAG AA(최소 4.5:1)를 충족합니다.
- 초록 강조색은 정보 전달용이 아니라 장식용입니다.
- 적록 색상 구분에 의존하지 않습니다.

### 확장성
- 벡터 형식으로 어떤 크기에서도 선명합니다.
- 기하학적 형태는 16px에서도 알아볼 수 있습니다.
- 사용 가능한 크기에 따라 디테일이 단계적으로 늘어납니다.

## 파일 형식 세부 사항

### SVG 구조

모든 SVG 파일은 플랫 디자인입니다.
- 그라데이션 없음(단색만 사용)
- 필터 효과 없음(흐림, 광채, 그림자 없음)
- 깔끔한 선(stroke) 및 채우기(fill) 도형
- 반응형 크기 조절을 위한 ViewBox
- 읽기 쉽고 주석이 달린 코드

### 브라우저 간 호환성

- Chrome/Edge: 완전 지원
- Firefox: 완전 지원
- Safari: 완전 지원
- iOS Safari: 완전 지원
- 모든 최신 브라우저: 완전 지원

## 사용자 지정

### 강조 색상 변경

다른 강조색을 사용한 변형을 만들려면 다음을 따릅니다.

1. 모든 `#22C55E`를 원하는 강조색으로 바꿉니다.
2. 장식 요소의 대비율이 3:1 이상으로 유지되는지 확인합니다.
3. 검정/흰색/회색 구조는 그대로 유지합니다.

### 크기 조절

```css
svg {
  width: 256px;
  height: 256px;
}
```

SVG는 viewBox를 통해 자동으로 크기가 조절되므로 transform이 필요하지 않습니다.
