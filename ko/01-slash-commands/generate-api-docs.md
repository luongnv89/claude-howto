# API 문서 생성기

다음과 같은 방식으로 API 문서를 생성합니다:

1.  `/src/api/`의 모든 파일을 스캔하여
2.  함수 시그니처와 JSDoc 주석을 추출하고
3.  엔드포인트/모듈별로 정리하며
4.  예시를 포함한 마크다운을 생성하고
5.  요청/응답 스키마를 포함하며
6.  오류 문서를 추가합니다.

출력 형식:
- `/docs/api.md`에 마크다운 파일 생성
- 모든 엔드포인트에 대한 curl 예시 포함
- TypeScript 타입 추가
