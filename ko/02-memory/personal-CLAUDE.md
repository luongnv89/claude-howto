# 저의 개발 선호 사항

## 저에 대하여
- **경험 수준**: 8년 풀스택 개발
- **선호 언어**: TypeScript, Python
- **소통 방식**: 예시를 통한 직접적인 방식
- **학습 방식**: 코드를 포함한 시각적 다이어그램

## 코드 선호 사항

### 오류 처리
저는 try-catch 블록과 의미 있는 오류 메시지를 사용하여 명시적으로 오류를 처리하는 것을 선호합니다.
일반적인 오류는 피하세요. 디버깅을 위해 항상 오류를 로깅하세요.

### 주석
주석은 '무엇'이 아닌 '왜'를 설명하는 데 사용하세요. 코드는 자체적으로 문서화되어야 합니다.
주석은 비즈니스 로직이나 명확하지 않은 결정을 설명해야 합니다.

### 테스트
저는 TDD (테스트 주도 개발)를 선호합니다.
구현 전에 테스트를 먼저 작성하세요.
구현 세부 사항보다는 동작에 초점을 맞추세요.

### 아키텍처
저는 모듈화되고 느슨하게 결합된 설계를 선호합니다.
테스트 용이성을 위해 의존성 주입을 사용하세요.
관심사를 분리하세요 (Controllers, Services, Repositories).

## 디버깅 선호 사항
- `[DEBUG]` 접두사와 함께 console.log 사용
- 컨텍스트 포함: 함수 이름, 관련 변수
- 가능한 경우 스택 트레이스 사용
- 로그에 항상 타임스탬프 포함

## 소통
- 복잡한 개념은 다이어그램으로 설명
- 이론 설명 전에 구체적인 예시 제시
- 변경 전/후 코드 스니펫 포함
- 마지막에 핵심 요약

## 프로젝트 구성
저는 프로젝트를 다음과 같이 구성합니다:
```
project/
  ├── src/
  │   ├── api/
  │   ├── services/
  │   ├── models/
  │   └── utils/
  ├── tests/
  ├── docs/
  └── docker/
```
